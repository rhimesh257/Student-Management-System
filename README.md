# Student Management System

## Description

The Student Management System is a Python-based mini project designed to manage student records efficiently through a simple menu-driven console application.

## Features

- Add Student
- View All Students
- Search Student
- Update Marks
- Delete Student
- Calculate Result
- Display Topper
- Display Failed Students
- Display Total Student Count
- Exit

## Technologies Used

- Python 3
- Lists
- Dictionaries
- Functions
- Loops
- Conditional Statements

## How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Run the following command:

```bash
python Mini_project.py
